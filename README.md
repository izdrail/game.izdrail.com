# game.izdrail.com

A lightweight OpenGL game project built as a learning and experimentation platform.

## Features
- Modern OpenGL rendering
- Cross-platform (Linux, macOS)
- CMake-based build system
- Modular architecture

## Requirements
- CMake ≥ 3.20
- OpenGL 3.3+
- GLFW
- GLAD
- C++17 compiler

## Build

```bash
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
cmake --build .
```

## Run

```bash
./game
```
